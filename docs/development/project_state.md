- Версия приложения по просмотренным метаданным: `0.1.0`. Редакция условий использования `1.0` — отдельное обозначение.

- Контакт для запросов: `vadim.l.solodyuk@gmail.com`.
- Упоминание MIT присутствовало уже в первоначальном README. Новые условия не отменяют ранее правомерно полученные права; последствия прежнего заявления отдельно не установлены.
- Каждая запись в GitHub, включая Issues и этот файл, — только после подтверждения пользователем точного состава изменений. Разрешение коннектору не заменяет согласование конкретной записи.
- Рабочие статусы: запланировано, в работе, на согласовании, требует проверки, завершено, отложено. Записанное, но непроверенное изменение не обозначать как подтверждённо работающее.
- Самостоятельные задачи по мере начала выделять в отдельные Issues и связывать с общей Issue #1; подробности не дублировать в этом файле.
- После рабочего этапа согласовывать фиксацию результата, проверок, ограничений и следующего шага. Не обещать автоматического обновления без подтверждения.
