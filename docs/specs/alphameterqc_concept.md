# Концепция приложения AlphaMeterQC

Статус: черновик.

## 1. Назначение приложения

Приложение AlphaMeterQC предназначено для контроля поступления и анализа корректности данных о параметрах электросети цепей учёта электрической энергии в БД ПО «АльфаЦЕНТР».

Первая версия автоматизирует получение из БД необходимых для анализа данных о параметрах электросети, выполнение согласованных проверок и подготовку результатов.  В дальнейшем приложение будет расширяться дополнительными функциями контроля и анализа данных.

## 2. Стейкхолдеры

| Стейкхолдер | Роль | Ключевые интересы и потребности |
|---|---|---|
| Инженеры отдела системного сопровождения | Основные пользователи приложения | Контроль большого объёма данных о параметрах электросети, который сложно охватить вручную. Снижение риска ошибок, связанных с человеческим фактором. Единообразное выполнение согласованных проверок. Понятные результаты: какие данные не поступили, какие отклонения выявлены и какие проверки не удалось выполнить. |
| Руководитель отдела системного сопровождения | Внутренний заказчик | Повышение надёжности работы автоматизированной системы комплексного учёта энергоресурсов (АСКУЭР) за счёт своевременного выявления непоступивших и некорректных данных о параметрах электросети цепей учёта электрической энергии. Снижение трудозатрат отдела на контроль и анализ данных. |
