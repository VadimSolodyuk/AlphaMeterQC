## 2. Цель создания
{{Бизнес-цель, решаемая проблема, ожидаемые бизнес-показатели успеха (метрики)}}

В ПО АльфаЦЕНТР для каждого присоединения инженером устанавливаются интервал и конфигурационные праметры
опроса прибора учёта (ПУ), которые установлены на территориально удалённых объектах.
Автоматический опрос ПУ выполняется сервисом АльфаЦЕНТР - AlphaSrv, который постоянно выполняется на сервере как служба.
Периодически на некоторых объектах ухудшается качество сигнала (GSM) в сети передачи данных
, что приводит к обрыву связи во время опроса и отсутствию актуальных данных в БД АльфаЦЕНТР.
В таких случаях инженерам необходимо в ручном режиме уменьшать интервал и корректировать конфигурационные праметры
опроса каждого ПУ, а при восстановлении качества сигнала в сети восстанавливать начальные настройки,
чтобы не допустить превышения лимита минут установленного тарифом оператора связи для опрашивающих sim-карт.
Для оптимизации процесса автоматического опроса ПУ за счёт динамического управления интервалом
и конфигурационными праметрами опроса в зависимости наличия данных в БД АльфаЦЕНТР, необходимо
разработать модуль `ext_alphaSrv`, который должен: периодического (1 раз в час начиная с 04:00) выполнения
