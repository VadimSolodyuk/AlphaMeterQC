# Проектирование подсистемы базы данных

Статус: проектный задел, не интегрирован в AlphaMeterQC.

Материалы требуют проверки и доработки перед использованием.
Их размещение не означает согласования всех решений, готовности
к эксплуатации или подтверждения приведённых результатов.

## Структура

- `design/` — концепция, требования и модели.
- `database/schema/` — проект SQL-схемы, не готовые миграции.
- `database/seeds/` — скрипт наполнения; назначение данных требует проверки.
- `database/security/` — проект настройки прав и ролей.
- `operations/` — инструкции развёртывания и политика безопасности.
- `scripts/` — проектные сценарии резервного копирования и восстановления.
- `tests/performance/` — данные для нагрузочных проверок.
- `performance/` — материалы оптимизации, анализ и отчёты.

## Ограничения

SQL и shell-скрипты не подключены к автоматическому запуску.
Перед применением необходимо проверить целевую СУБД, зависимости,
пути, параметры подключения и безопасность операций.

После реорганизации требуется проверить ссылки в документации
и файловые пути внутри скриптов. Исходные тексты артефактов
при переносе не изменяются.
