# Макет диалога подключения к БД

Сохраняемый интерактивный макет этапа проектирования интерфейса модуля `login_dialog`.

Макет предназначен для изучения расположения элементов, навигации Tab и маскировки пароля. Он не является рабочей реализацией диалога и не обязан повторять последующие изменения приложения.

## Запуск

Из корня репозитория, в активированном окружении с установленными зависимостями проекта:

```bash
python prototypes/login_dialog/prototype.py
```

Требуются CustomTkinter и доступная графическая среда Tk. Команда приведена для запуска в целевой среде; в рамках подготовки переноса GUI не запускался.

## Ограничения

- Подключение к БД не выполняется.
- Валидация и сохранение параметров не реализованы.
- Кнопка «Ок» отключена; обработчик подтверждения — заглушка.
- Отдельная обработка Esc не реализована.
- Маскировка пароля в поле ввода присутствует.
- Вывод введённого пароля удалён при сохранении макета вне рабочего пакета.
- Для проверки используйте только вымышленные параметры, не реальные учётные данные.
